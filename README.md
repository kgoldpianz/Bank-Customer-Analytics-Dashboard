# Bank-Customer-Analytics-Dashboard
An Excel-based banking data analytics project exploring customer demographics, account balances, deposits, loans, transaction patterns and customer segmentation.

## Project Overview
This project explores banking customer data to understand customer demographics, account activities, financial balances, loan information and transaction patterns using Microsoft Excel.

## Project Objectives
- Analyse customer demographics and account distribution.
- Examine customer balances and bank deposits.
- Explore loan and transaction activities.
- Identify high-value customers and customer reward patterns.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Charts and Dashboard

## Key Areas of Analysis
- Customer demographics
- Account type distribution
- Customer balances and deposits
- Loan analysis
- Transaction types and channels
- Customer segmentation

## Conclusion
The project demonstrates how Excel can be used to organise, analyse and visualise banking data to generate insights into customer behaviour and banking activities.
